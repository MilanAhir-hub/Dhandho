# Web Design & UI/UX Craftsmanship Skill

This skill provides comprehensive instructions, tokens, and component archetypes for building world-class web user interfaces with exceptional visual hierarchy, typography, and layout balance.

---

## 1. The Warm Editorial & Modern Commerce Design Language

Modern store management systems often look ugly, outdated, and intimidating. We use clean, high-contrast, modern UI cards with warm neutral backdrops, crisp borders, and vibrant status colors.

### Color Tokens
- **Canvas (`#f8fafc` or `#faf9f5`)**: Clean, non-glaring background.
- **Surface Card (`#ffffff`)**: Clean card backgrounds with subtle border `border-slate-200/80`.
- **Primary / Dhandho Accent (`#059669`)**: Indian commercial green, symbolizes prosperity and cash flow.
- **Dena Hai / Alert (`#e11d48`)**: Clear rose-red for credit / udhar.
- **Lena Hai / Success (`#16a34a`)**: Clear green for receivables.
- **Warning / Low Stock (`#d97706`)**: Amber for inventory warnings.

---

## 2. Typography & Form Controls
- Font: Inter or system UI for interface (`font-sans`), monospace tabular numbers for money (`font-mono tabular-nums`).
- Input fields: Large touch/click targets (minimum `h-11`), high contrast focus rings (`focus:ring-2 focus:ring-emerald-500/20 focus:border-emerald-600`).
- Large CTAs for final bill actions ("Save Bill & Print", "Pay via UPI", "Add to Khata").
